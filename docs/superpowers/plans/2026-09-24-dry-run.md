# Dry Run Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-command `dry_run` mode that moves the arm through a sequence for real with the blade held clear of the box, checking frames and workspace bounds along the way.

**Architecture:** Every `motion.move` call in `src/models/control.py` is routed through one `_move()` method. With `dry_run` off, it calls `motion.move` and nothing else, so real runs are unchanged. With `dry_run` on, it checks that the frames exist (once per command), skips blade insert/retract moves (recording their labels), and checks the target against configured workspace bounds before sending the move. Approach standoffs are raised by `dry_run_clearance_mm` where the sequences compute them.

**Tech Stack:** Python 3.13, Viam Python SDK 0.80, pytest + pytest-asyncio (`asyncio_mode = auto`).

**Spec:** `docs/superpowers/specs/2026-09-24-dry-run-design.md`

## Background for the implementer

- The service is `Control` in `src/models/control.py`. Commands arrive through `do_command`, which runs one command at a time as an `asyncio` task (`self._task`) and hands off to `_dispatch`.
- Tests build instances with `Control.__new__(Control)` and skip `reconfigure` (see `_make_control` in `tests/test_control_dispatch.py`). **Any new instance state needs a class-level default** (like `_task`), or existing tests fail with `AttributeError`. For the same reason, `self.logger` does not exist in tests; use a module-level logger.
- Test fakes in `tests/test_control_dispatch.py`:
  - `_RecordingMotion` records each move as `(component_name, destination, constraints)` in `.moves`.
  - `_FakeRobotClient.transform_pose` records `(pose_in_frame, dest_frame)` in `.requests`. Today it passes poses through unchanged for `"world"` and adds `TOOL_OFFSET = (1, 2, 3)` for any other destination frame. Task 5 extends it.
  - `_ServoCamera([column])` returns frames with a seam at that pixel column. A column equal to `blade_x_px` converges on the first frame, with no move.
  - `_control_with_box_frame(motion=None, attrs=None)` returns a control with `set_box` preset `box_1` applied and `find_center` run.
- Tool frame: +z points into the box (down). World frame: +z is up.
- Run tests with `venv/bin/python -m pytest` from the repo root. The baseline is **84 passed, 7 skipped, 4 xfailed**.
- Work on branch `feat/dry-run` (already checked out).

In `do_command`, replace everything from `task = asyncio.create_task(...)` to the end of the method with:

```python
        dry_run = bool(command.get("dry_run")) and name in DRY_RUN_COMMANDS
        skipped: list = []
        self._dry_run, self._skipped = dry_run, skipped
        task = asyncio.create_task(self._dispatch(name, command), name=name)
        self._task = task
        try:
            # `wait` rather than `await task`, so a `stop` cancelling the task
            # comes back as a result instead of cancelling this caller too.
            await asyncio.wait([task])
        except asyncio.CancelledError:
            # The caller went away (e.g. the client disconnected): don't leave
            # the arm running a sequence nobody is watching.
            task.cancel()
            raise
        finally:
            if self._task is task:
                self._task = None
            self._dry_run = False
        if task.cancelled():
            return {"stopped": True, "command": name}
        result = task.result()
        if dry_run:
            result = {
                **result,
                "dry_run": True,
                "skipped": skipped,
                "bounds_checked": self.settings.workspace_min_xyz is not None,
            }
        return result
```

    def __init__(self, fail_frames=()):
        self.requests = []
        self.fail_frames = set(fail_frames)

    async def transform_pose(self, pose_in_frame, dest_frame):
        self.requests.append((pose_in_frame, dest_frame))
        source = pose_in_frame.reference_frame
        if source in self.fail_frames:
            raise RuntimeError(f"frame {source} not found")
        p = pose_in_frame.pose
        # Camera points pass straight through to world. A camera point sent
        # to the tool frame, or a tool-frame pose sent to world, is offset so
        # tests can tell them apart.
        if dest_frame == "world" and source != "tool":
            x, y, z = p.x, p.y, p.z
        else:
            dx, dy, dz = self.TOOL_OFFSET
            x, y, z = p.x + dx, p.y + dy, p.z + dz
        return PoseInFrame(
            reference_frame=dest_frame,
            pose=Pose(x=x, y=y, z=z, o_x=0, o_y=0, o_z=-1, theta=0),
        )

Add after `_check_frames`:

```python
    async def _check_bounds(self, component_name: str, destination: PoseInFrame) -> None:
        """Refuse a dry-run move whose target leaves the configured workspace.

        A relative destination (tool or blade frame) is transformed to the world
        frame first, which is exactly where the move will put that frame.
        """
        s = self.settings
        if s.workspace_min_xyz is None:
            return
        if destination.reference_frame == s.world_frame:
            pose = destination.pose
        else:
            pose = (await self._transform(destination, s.world_frame)).pose
        outside = [
            f"{axis}={value:.1f} not in [{lo:.1f}, {hi:.1f}]"
            for axis, value, lo, hi in zip(
                "xyz",
                (pose.x, pose.y, pose.z),
                s.workspace_min_xyz,
                s.workspace_max_xyz,
            )
            if not lo <= value <= hi
        ]
        if outside:
            raise ValueError(
                f"dry run: {component_name} move leaves the workspace: "
                + "; ".join(outside)
            )
```

### Dry run

`home`, `jog`, `move_to_center`, `move_to_seam`, `converge`, `cut` and
`full_cut` accept `"dry_run": true`. The arm runs the sequence for real, but:

- blade inserts and retracts are skipped and listed in `skipped`;
- approach standoffs are raised by `dry_run_clearance_mm`;
- before the first move, every configured frame must exist in the frame system;
- if `workspace_min_xyz`/`workspace_max_xyz` are set, any move whose target
  leaves that volume is refused before it is sent.

A real run (no `dry_run`) does none of these checks and behaves exactly as
before.

```json
{ "command": "full_cut", "dry_run": true }
```

The normal response gains
`"dry_run": true, "skipped": ["top:insert", ...], "bounds_checked": true|false`.

**Commissioning order:** run `full_cut` with `dry_run` first and confirm every
move goes the way you expect, then run it for real.

**Caveat:** a dry-run `cut` only stays clear of the box if the move that
positioned the arm was also a dry run (`full_cut`, `move_to_center` or
`move_to_seam` with `dry_run`). After a real `move_to_center`, a dry-run top
cut slices at the real 20 mm standoff, where a raised flap can still be hit.
After a real `move_to_seam`, while `side_blade_insert_mm` is `0`, a dry-run
side cut takes the same path as a real one.
